MDUY MOD FF - Ignis customization UI update

This package includes an updated index.html with selectable Ignis slots:
Head, Mask, Face, Shirt, Pants, Shoes, Automatic, VFX settings and JSON selection export.

IMPORTANT:
- Clothing choices currently save a website/test selection only.
- Existing Alok catalog items are copied into the Ignis dropdowns as choices, but are NOT verified as compatible with Ignis.
- The JSON file is a manifest, not a Unity asset bundle or an in-game installer.
- Bundles have not been verified as compatible with a specific Free Fire version.

Upload index.html to replace the existing root index.html. The bundle files are included for convenience; if they already exist at assets/mods/, do not upload them again.
