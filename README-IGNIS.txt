MDUY MOD FF — Ignis customizer
- index.html: nút chọn Alok/Ignis, chọn trang phục demo, bật/tắt VFX mô phỏng, tạo ignis-selection.json.
- assets/mods/ignis-android.bundle: bundle được cung cấp cho Android Free Fire thường.
- assets/mods/ignis-fft-ios.bundle: bundle được cung cấp cho FFT iOS.
Cài lên GitHub Pages: thay index.html và tải hai bundle lên đúng đường dẫn assets/mods/.
Lưu ý: JSON là manifest lựa chọn cho website, không phải file mod đã được đóng gói/kiểm chứng để import trực tiếp vào game. VFX trong trang là mô phỏng CSS.
